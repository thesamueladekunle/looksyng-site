# LOOKSYNG Website

Personal style, in sync with your life. Nigerian fashion-technology service for busy professionals.

## Deploy

This is a static site. Upload the contents of this folder to Cloudflare Pages (or any static host).

- `index.html` is the entry point.
- Images are in `images/`.

No build step required.

## Git

```bash
git init
git add .
git commit -m "Initial LOOKSYNG site"
# push to GitHub, then connect to Cloudflare Pages
```
